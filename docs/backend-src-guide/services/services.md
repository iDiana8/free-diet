# Папка `src/services`: обзор

## Что это
Сервисный слой (business logic): модули сценариев, которые соединяют правила предметной области и работу с БД.

Файлы:
- `auth.service.js`
- `catalog.service.js`
- `daily.service.js`
- `nutrition.service.js`

## Архитектурная роль
Services:
- реализуют use-case,
- работают с SQL через `pool`/`client`,
- используют shared-правила из `lib`.

Routes при этом остаются тонкими.

## Почему это важно
- Меньше дублирования.
- Легче тестировать бизнес-правила.
- Проще рефакторить API, не ломая домен.

## Тезисно
- `services` = сердце backend.
