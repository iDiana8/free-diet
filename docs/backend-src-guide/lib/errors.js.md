# `src/lib/errors.js`

## Что это
Небольшой helper для прикладных ошибок с HTTP-статусом.

## Что там написано
- `createRequestError(message, statusCode = 400)`.
- Возвращает `Error` с дополнительным полем `statusCode`.

## Почему так пишут
- Сервисы бросают смысловые ошибки, а routes конвертируют их в корректный HTTP-ответ.

## С чем связано
- Используется в `services/catalog.service.js` и `services/daily.service.js`.

## На что влияет
- На точность кодов ответа (например, 400 вместо 500 при бизнес-ошибке).

## Что будет, если файла не будет
- Больше шансов отдавать неправильные ошибки клиенту.

## Тезисно
- `errors.js` стандартизирует сигнализацию ошибок между слоями.
