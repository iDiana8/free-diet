# `src/lib/config.js`

## Что это
Модуль централизованной конфигурации backend.

## Что там написано
- Загрузка `.env` через `dotenv`.
- `getNumberEnv(name, fallback)` — безопасный парсинг чисел.
- `getRequiredEnv(name, fallback)` — проверка обязательных переменных.
- `getConfig()` — единый объект конфигурации:
  - `port`, `clientUrl`, `authSecret`,
  - `db.{host,port,user,password,database}`.

## Почему так пишут
- Конфиг читается в одном месте.
- Ошибки окружения проявляются при старте, а не в случайный момент runtime.

## С чем связано
- Используется в `index.js`, `app.js`, `db.js`, `auth.middleware.js`, `auth.routes.js`.

## На что влияет
- На запуск сервера, CORS, подпись токенов и подключение к БД.

## Что будет, если файла не будет
- Появится хрупкий хардкод `process.env` по всему проекту.

## Тезисно
- `config.js` = единая точка правды для ENV.
