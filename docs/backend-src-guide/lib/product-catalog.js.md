# `src/lib/product-catalog.js`

## Что это
Доменные helper-функции для каталога продуктов.

## Что там написано
- Наборы допустимых секций:
  - `FOOD_SECTION_KEYS`
  - `DRINK_SECTION_KEYS`
  - `WATER_SECTION_KEYS`
- `normalizeProductName(value)` — нормализация названия.
- `buildProductConfigBySection(sectionKey)` — выбор `product_kind`, `unit_label`, `allowed_sections`.

## Почему так пишут
- Нормализация нужна для дедупликации и корректного поиска.
- Конфиг по секции предотвращает доменные ошибки (например, вода как еда).

## С чем связано
- Используется в `services/catalog.service.js`.

## На что влияет
- На качество каталога и бизнес-правила добавления продуктов.

## Что будет, если файла не будет
- Появятся дубли и невалидные связи "продукт -> секция".

## Тезисно
- `product-catalog.js` держит "правила предметной области" для каталога.
