# `src/index.js`

## Что это
Точка входа backend-процесса.

## Что там написано
- Импортируются `app`, `pool`, `getConfig`, `syncNutritionCatalog`.
- Читается `config.port`.
- При старте выполняется `syncNutritionCatalog(pool)`.
- Затем вызывается `app.listen(...)`.
- В случае ошибки старта процесс завершается через `process.exit(1)`.

## Почему так пишут
- Инициализацию делают до запуска сервера, чтобы не принимать запросы в "полусобранном" состоянии.
- Ошибка старта должна быть явной, а не тихой.

## С чем связано
- С `services/catalog.service.js`: подготовка каталога.
- С `app.js`: HTTP-слой.
- С `db.js`: соединение с БД.
- С `lib/config.js`: параметры окружения.

## На что влияет
- На стабильность cold-start.
- На то, что каталог продуктов гарантированно готов после запуска.

## Что будет, если этого файла не будет
- `npm start` не сможет поднять backend (нет entrypoint).

## Тезисно
- `index.js` = orchestration startup.
- Это "дирижер", а не место для бизнес-правил.
