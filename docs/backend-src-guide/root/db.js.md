# `src/db.js`

## Что это
Инфраструктурный модуль подключения к PostgreSQL.

## Что там написано
- Импорт `Pool` из `pg`.
- Получение настроек через `getConfig()`.
- Создание `new Pool(config.db)`.
- Экспорт единого `pool`.

## Почему так пишут
- Один pool на процесс — стандартный паттерн для Node.js + PostgreSQL.
- Это уменьшает overhead на открытие соединений.

## С чем связано
- С `lib/config.js` (host/port/user/password/database).
- С routes/services, которым нужен доступ к SQL.

## На что влияет
- На производительность и устойчивость доступа к БД.

## Что будет, если этого файла не будет
- Все запросы к БД перестанут работать.

## Тезисно
- `db.js` инкапсулирует детали подключения.
- Остальной код работает с абстракцией `pool`.
