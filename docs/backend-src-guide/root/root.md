# Папка `src` (корневые файлы): обзор

В корне `backend/src` лежат 3 системных файла, которые запускают backend и связывают инфраструктуру:

- `index.js` — старт процесса.
- `app.js` — сборка HTTP-приложения (Express).
- `db.js` — подключение к PostgreSQL.

Архитектурная идея:
- `index.js` отвечает за lifecycle.
- `app.js` отвечает за HTTP-конвейер.
- `db.js` отвечает за доступ к данным.

Это разделение дает чистые ответственности: запуск, API, БД.

## Тезисный обзор
- Файлы в корне `src` формируют базовый runtime-контур.
- Они не содержат "бизнеса" питания, только каркас исполнения.
- Если их смешать с domain-логикой, поддержка проекта станет сложнее.
