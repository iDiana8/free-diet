# `src/app.js`

## Что это
Композиция Express-приложения.

## Что там написано
- Создается `express()`.
- Подключается `cors` с origin из конфигурации.
- Подключается `express.json({ limit: '1mb' })`.
- Регистрируются маршруты `/api/health`, `/api/auth`, `/api/catalog`, `/api/daily`.
- Добавляется fallback 404-handler.

## Почему так пишут
- `app.js` отделяют от `index.js`, чтобы:
  - проще тестировать app без запуска порта,
  - не смешивать lifecycle и HTTP-конфигурацию.

## С чем связано
- С `lib/config.js` (настройка CORS).
- Со всеми файлами в `routes/*`.

## На что влияет
- На порядок middleware.
- На доступность маршрутов и формат body.

## Что будет, если этого файла не будет
- Нельзя собрать Express app, маршрутизация исчезнет.

## Тезисно
- `app.js` = точка, где строится HTTP-конвейер.
- Здесь определяются "правила входа" для API.
