# Папка `src/middleware`: обзор

## Что это
Middleware-слой HTTP-конвейера. Здесь лежат функции, которые выполняются между получением запроса и route-handler.

В текущем проекте:
- `auth.middleware.js`.

## Архитектурная роль
- Проверяет общие правила запроса до бизнес-логики.
- Снимает дублирование с маршрутов.

## Что будет, если убрать middleware-слой
- Придется копировать проверки в каждый route.
- Повысится риск дыр в безопасности.

## Тезисно
- Middleware = переиспользуемые gatekeeper-функции API.
