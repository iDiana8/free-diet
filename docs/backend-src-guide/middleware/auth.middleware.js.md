# `src/middleware/auth.middleware.js`

## Что это
Middleware обязательной авторизации для защищенных endpoint.

## Что там написано
- Читает заголовок `Authorization`.
- Извлекает Bearer-token.
- Проверяет токен через `verifyToken(token, authSecret)`.
- При успехе записывает пользователя в `request.user`.
- При ошибке возвращает `401`.

## Почему так пишут
- Авторизация должна быть централизованной.
- Routes получают уже проверенного пользователя и не дублируют парсинг токена.

## С чем связано
- `lib/config.js` (секрет).
- `lib/crypto.js` (проверка подписи).
- `routes/auth.routes.js`, `routes/catalog.routes.js`, `routes/daily.routes.js` (применение middleware).

## На что влияет
- На безопасность приватных API.
- На удобство дальнейшей логики (в `request.user` уже есть `id/email/name`).

## Что будет, если файла не будет
- Защищенные маршруты станут незащищенными или начнут дублировать auth-логику вручную.

## Тезисно
- Это "входная охрана" для пользовательских данных.
