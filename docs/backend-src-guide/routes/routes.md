# Папка `src/routes`: обзор

## Что это
HTTP-слой API: здесь определяются endpoint, валидация запроса, вызов сервисов и формирование HTTP-ответа.

Файлы:
- `health.routes.js`
- `auth.routes.js`
- `catalog.routes.js`
- `daily.routes.js`

## Архитектурная роль
Routes должны:
- принять и проверить вход,
- вызвать service,
- вернуть корректный статус/JSON.

Routes не должны:
- содержать тяжелую бизнес-логику,
- делать сложные вычисления, не связанные с HTTP.

## Что будет, если убрать routes
- Входные точки API исчезнут.

## Тезисно
- `routes` = адаптер между HTTP и доменной логикой.
