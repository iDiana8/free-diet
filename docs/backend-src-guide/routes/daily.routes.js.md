# `src/routes/daily.routes.js`

## Что это
Маршруты дневника питания на конкретную дату.

## Что там написано
Endpoint:
- `GET /api/daily/:date`
- `PUT /api/daily/:date`

Логика:
- Проверка формата даты.
- Для `PUT` — полная валидация payload дневника.
- Оба endpoint требуют `requireAuth`.
- Работа через `daily.service.js`.

## Почему так пишут
- Дневник — основной сценарий продукта, его route должен быть четким и защищенным.
- Валидация на границе снижает риск некорректных данных.

## С чем связано
- `db.js`, `middleware/auth.middleware.js`, `lib/validation.js`, `services/daily.service.js`.

## На что влияет
- На сохранность пользовательских записей и качество аналитики дня.

## Что будет, если файла не будет
- Пропадет ключевой функционал (чтение и сохранение дневника).

## Тезисно
- Это маршрут-ядро сценария "внести еду за день".
