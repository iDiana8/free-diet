# Папка `src/data`: обзор

## Что это
`data` хранит встроенные данные проекта (seed), которые backend использует для первичного наполнения каталога.

В текущем проекте:
- `nutrition-products.json` — справочник продуктов и нутриентов.

## Почему это отдельная папка
- Данные отделены от кода.
- Легче обновлять справочник без изменения бизнес-логики.

## С чем связано
- Прямо используется в `services/catalog.service.js` при синхронизации каталога.

## Что будет, если убрать папку `data`
- Каталог при старте не получит базовые продукты.
- Пользовательский опыт сильно ухудшится (ручной ввод всего списка).

## Тезисно
- `data` = источник стартовых доменных данных.
- Это не runtime-логика, а материал для инициализации БД.
