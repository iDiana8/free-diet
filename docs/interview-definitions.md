# База терминов для собеседований (JS + Web)

## JavaScript

- **Переменная (variable)**: именованная ссылка на значение в памяти.
- **Константа (`const`)**: переменная, которую нельзя переопределить (но объект внутри можно менять).
- **Функция (function)**: блок кода, который можно вызывать много раз с разными аргументами.
- **Метод (method)**: функция, которая является свойством объекта.
- **Аргумент (argument)**: конкретное значение, переданное в функцию при вызове.
- **Параметр (parameter)**: имя переменной в объявлении функции.
- **Объект (object)**: структура данных из пар `ключ: значение`.
- **Массив (array)**: упорядоченная коллекция значений.
- **Замыкание (closure)**: функция, которая помнит переменные из внешней области видимости.
- **Область видимости (scope)**: место в коде, где переменная доступна.
- **Контекст `this`**: объект, к которому относится текущий вызов функции.
- **Промис (Promise)**: объект для работы с асинхронным результатом (`pending/fulfilled/rejected`).
- **`async/await`**: синтаксис для удобной работы с Promise.
- **Событие (event)**: сигнал о действии пользователя или системы (клик, submit, load).
- **Event Loop**: механизм, который координирует выполнение синхронного и асинхронного кода в JS.

## Frontend

- **Компонент (component)**: независимая часть UI, которая принимает данные и рендерит интерфейс.
- **Пропсы (props)**: входные данные компонента.
- **Состояние (state)**: внутренние данные компонента, влияющие на рендер.
- **Рендер (render)**: построение UI из текущего состояния и пропсов.
- **Хук (hook)**: функция React для управления state, эффектами и логикой.
- **SPA (Single Page Application)**: приложение, где навигация происходит без полной перезагрузки страницы.

## Backend

- **API (Application Programming Interface)**: контракт, по которому системы общаются между собой.
- **Endpoint**: конкретный URL + HTTP-метод, например `GET /api/users`.
- **Маршрут (route)**: правило, которое связывает запрос и обработчик на сервере.
- **Контроллер (controller)**: код, который принимает запрос и возвращает ответ.
- **Сервис (service layer)**: слой бизнес-логики между контроллером и БД.
- **Middleware**: функция в Express, которая обрабатывает запрос до/после контроллера.
- **Валидация (validation)**: проверка входных данных на корректность.
- **Аутентификация (authentication)**: проверка, кто пользователь.
- **Авторизация (authorization)**: проверка, что пользователю разрешено.

## База данных

- **Таблица (table)**: набор строк и столбцов.
- **Запись/строка (row/record)**: один объект данных в таблице.
- **Первичный ключ (primary key)**: уникальный идентификатор строки.
- **Внешний ключ (foreign key)**: связь между таблицами.
- **Индекс (index)**: структура для ускорения поиска.
- **Миграция (migration)**: версия изменений схемы БД.
- **Транзакция (transaction)**: группа SQL-операций, выполняемых как единое целое.

## Сеть и архитектура

- **HTTP**: протокол обмена данными между клиентом и сервером.
- **HTTP-методы**: `GET` (чтение), `POST` (создание), `PUT/PATCH` (обновление), `DELETE` (удаление).
- **Статус-код**: результат запроса (`200`, `201`, `400`, `401`, `404`, `500` и т.д.).
- **JSON**: текстовый формат обмена данными.
- **REST**: архитектурный стиль API, ориентированный на ресурсы.
- **CORS**: правила, по которым браузер решает, можно ли делать cross-origin запросы.

## Git

- **Репозиторий (repository)**: хранилище истории проекта.
- **Коммит (commit)**: зафиксированный снимок изменений.
- **Ветка (branch)**: независимая линия разработки.
- **Merge**: объединение веток.
- **Pull Request (PR)**: запрос на вливание изменений в основную ветку.


SSH — это сетевой протокол для зашифрованного соединения между клиентом и сервером, через который можно безопасно передавать данные.
