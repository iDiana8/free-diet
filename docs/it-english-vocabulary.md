# IT English словарик (для разработки)

## Базовые слова, которые встречаются постоянно

- **feature** — фича, функциональность
- **bug** — баг, ошибка
- **issue** — проблема/задача
- **fix** — исправление
- **release** — релиз
- **deploy** — выкатывать на сервер
- **rollback** — откат версии
- **deadline** — дедлайн
- **estimate** — оценка по времени
- **requirement** — требование

## Frontend

- **button** — кнопка
- **input** — поле ввода
- **form** — форма
- **layout** — макет/компоновка
- **responsive** — адаптивный
- **state** — состояние
- **render** — рендерить (отрисовывать)
- **event handler** — обработчик события
- **dropdown** — выпадающий список
- **modal** — модальное окно

## Backend / API

- **request** — запрос
- **response** — ответ
- **payload** — полезные данные запроса/ответа
- **endpoint** — endpoint API
- **route** — маршрут
- **controller** — контроллер
- **service** — сервисный слой
- **middleware** — промежуточная обработка
- **validation** — валидация
- **authorization** — авторизация

## Database

- **table** — таблица
- **column** — столбец
- **row** — строка
- **query** — SQL-запрос
- **join** — соединение таблиц
- **index** — индекс
- **constraint** — ограничение
- **migration** — миграция
- **seed** — тестовые/стартовые данные
- **transaction** — транзакция

## Полезные фразы на дейликах и в задачах

- **I reproduced the bug.** — Я воспроизвела баг.
- **I pushed the fix to the branch.** — Я запушила фикс в ветку.
- **The endpoint returns 500.** — Endpoint возвращает 500.
- **I need more context for this task.** — Мне нужен дополнительный контекст по задаче.
- **Can you review my PR?** — Можешь посмотреть мой PR?
- **This logic should be moved to the backend.** — Эту логику лучше перенести на бэкенд.
- **Let's add validation before saving to DB.** — Давай добавим валидацию перед сохранением в БД.
- **I will split this task into smaller steps.** — Я разобью эту задачу на более мелкие шаги.

## Мини-шпаргалка глаголов

- **create** — создать
- **read/fetch** — прочитать/получить
- **update** — обновить
- **delete/remove** — удалить
- **handle** — обработать
- **store/save** — сохранить
- **parse** — распарсить
- **validate** — проверить корректность
- **refactor** — улучшить структуру кода без изменения поведения
- **debug** — искать и исправлять ошибку
